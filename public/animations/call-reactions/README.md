# SociaLens Call Reaction Animation Assets

Place the downloaded animated emoji assets for call reactions in this folder.

## What to add
- Prefer the original **Lottie JSON** (`.json`) or **dotLottie** (`.lottie`) animation file.
- If an emoji is not available in Lottie format, use an **animated WebP** or **APNG** only if it has a transparent background.
- Do not add MP4/video files, preview screenshots, website thumbnails, or files with a solid background.
- If the download is a ZIP, extract it first and place only the actual animation asset(s) here.

## Before adding assets
- Check that the animation background is transparent.
- Check the asset's license and retain any required attribution/license notice.
- Use clear filenames, for example: `flying-heart.json`, `heart-eyes.lottie`, `red-heart.webp`.

The app integration will be done only after the assets are reviewed and their formats, transparency, and licenses are verified.
